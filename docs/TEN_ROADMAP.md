# Ten implementation checklist

Implemented in 0.1.0:
- Separate install identity and first-preview version.
- Flat taskbar, Start rail/app list, grouped/resizable/saved tiles and search.
- Task View window cards and Android app shortcuts; private preview exclusion.
- Action Center alerts and quick actions.
- Native Settings home and initial System/personalization pages.
- Explorer ribbon tied to real operations.
- Nth Nota optional free cloud writing panel.
- Original blue light wallpaper, launch tile and introduction.
- Inherited guided setup, window geometry, Snap, file operations and media tools.

Next passes:
1. Device testing against all 49 references, especially narrow portrait taskbar spacing, gesture navigation and cutouts.
2. Multiple named virtual desktops for built-in tools; move windows between desktops and keep their sessions separate.
3. Editable tile group names, optional full-screen/tablet Start, more live data and accessible keyboard tile reordering.
4. Complete the Ten Settings sidebar and page hierarchy, including search and consistent Android setting destinations.
5. Complete Explorer ribbon expansion/collapse, selection-aware disabled states and status density.
6. Browser UI inspired by the supplied modern browser usage; preserve real WebView security behavior.
7. Nota local-AI-first adapter, supported-device preparation and transparent free cloud fallback.
8. Optional real Android notifications after notification-listener integration; optional news/weather panel.
9. Re-run and adapt inherited engine regressions, starting with the three known Seven Android 11 failures.

A green Ten smoke suite verifies only its documented coverage. Live external services and complete legacy parity require additional checks.
