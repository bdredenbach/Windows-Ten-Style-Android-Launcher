# Ten 0.11.0 — direct app opening in Nth Nota

A user sends `open Audible` or `can you open audible` in Write or Desktop & phone mode. When exactly one installed app matches its name or saved alias, Nota dispatches that app's normal Android launcher intent immediately. Nth tools such as Browser, Calculator and Notepad also open directly when the command resolves uniquely. No AI model, cloud permission or model preparation is needed.

Automatic opening belongs to a resolved app-opening plan and runs only from the composer's Send handler. It does not run while typing, when tapping a suggestion chip, when reading history, on return from an app, from a help card, or from generated/imported text. Settings links, web/file searches and other desktop actions keep their explicit shortcuts. Unknown app names offer Find an app in Start without automatically opening Start. Names shared by multiple apps, or by an installed app and an Nth tool, require a choice.

Choices now look like controls rather than reply text: a 64 dp minimum touch target, the installed app's actual PackageManager icon (or the corresponding Nth/settings icon), an 18 sp bold label and a chevron. Their background and foreground follow the app theme. Short command feedback also uses 18 sp bold text; writing replies retain their normal paragraph style. A single manual shortcut says `Found the shortcut. Click the shortcut above.` Ambiguous matches say `Found matching apps. Click the shortcut you want above.` The card stays available after use so it can be reopened or retried.

An automatic open reports `Opening Audible` and retains the same icon-bearing shortcut for later use. Ordinary app launches and Nota launches share the launch/error path. An app that has been removed or disabled reports failure rather than claiming it opened.

The portable command checks include the Audible wording, unique installed/Nth matches, duplicate names, built-in/installed collisions and manual-only help/settings/search/missing-app cases. Native command regression uses synthetic installed aliases named Audible and Nota duplicate: it observes a real Android app launch without a shortcut tap, checks that returning does not replay it, requires a tap for duplicate names, checks actual icons and bold label size/contrast in both orientations and app modes, and retains the imported/generated-text boundaries. The fixture aliases are test-only and are not included in the launcher APK.
