# Ten 0.10.0 — reference layouts and device settings

The owner's supplied Windows 10 captures guide this pass. Personal screenshots and their contents are not included in the repository.

- Folder artwork now uses an upright gold spine, rear cover, white paper inserts and an angled yellow front cover. Documents, Pictures, Music, Videos and Downloads have their own small content marks. The shared icon renderer updates desktop folders, app folders and Explorer shortcuts together.
- Taskbar Search opens a dedicated landing page with All, Apps, Documents and Web tabs, a More menu for Settings and Folders, Recent, Top apps and Quick searches. The wide layout places Recent beside the app tiles; portrait stacks the groups. Results still open real installed apps, linked documents, Settings and explicit web searches. Normal Start retains its app list and pinned tiles. Search does not raise the Android keyboard until the user enters the search field.
- Task View places New desktop at the upper left and shows unframed window previews over the current dimmed wallpaper. Thumbnails retain each window's proportions and wrap within screen bounds. The wallpaper snapshot is opaque even when the source renderer uses translucent gradients, so underlying windows cannot leak through. Multiple desktops expose the existing selection/rename/move/close controls. Private previews remain hidden, and external Android apps use labeled launch cards rather than invented screenshots.
- News and Interests has a compact icon toolbar, a featured story across the main column, smaller story cards, a Top stories group and a sidebar with Markets links, weather and game tiles. On portrait, weather appears immediately after the lead story. News and images still use the user's configured feed and image preference. Market links open current reports; the dashboard does not fabricate prices or changes. Save, Nota, feed configuration, retry/cancellation and cached weather behavior remain functional.
- Holding Start or pressing Win+X shows the complete grouped, dark, icon-free reference menu. The order includes Apps and Features, Power Options, Event Viewer, System, Device Manager, Network Connections, Disk Management, Computer Management, Windows PowerShell and its Admin entry, then Task Manager, Settings, Explorer, Search and Run, followed by power and Desktop. Android counterparts expose actual session events, sensor/input/feature inventory and management shortcuts. Nth PowerShell supports a small documented set of desktop commands. Neither PowerShell entry requests or claims Windows administrator privileges.
- System → About shows RAM, processor, graphics capability and storage cards, a local device-name control, copyable/collapsible Device specifications and Android & launcher specifications, and related settings. Metadata includes model/manufacturer, SoC where available, logical cores, memory, ABI, board/hardware, battery, display pixels/density/refresh rate, input capability, Android/API/security patch, build/fingerprint, bootloader, kernel, uptime, locale/time zone, package/version and installation/update dates. Graphics reports supported APIs, not invented GPU memory. The editable name applies inside Nth Desktop only.
- Personalization → Fonts provides ten bundled/device font families with search, editable preview text and a persistent launcher font choice. Previews retain their own face while other launcher text follows the selected font. Fonts use real family names; unavailable proprietary Windows families are not relabeled Android fonts. Both the font and local device name round-trip through validated backups.

The new TenReferenceSmoke runner exercises Search filtering, metadata and Copy, font search/preview/application/backup, Task View bounds, Win+X destinations and news sections in portrait and landscape. The nine existing native runners remain in the workflow.
